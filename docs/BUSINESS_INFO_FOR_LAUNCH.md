## Browser tests that need a real test customer account

1. Register with a fresh email address and confirm the email link.
2. Sign in; verify the customer account and sign-out flow.
3. Close and reopen the browser; check whether login persistence behaves as intended.
4. Request a password reset; open the emailed link and change the password.
5. Check the old password fails and the new password succeeds.
6. Make a Stripe sandbox order as a guest using the same **confirmed** email; verify it appears in My Orders after sign in.
7. Sign in using a different test email; confirm the guest order does not appear.
8. Test failed and cancelled sandbox checkout, mobile responsiveness and customer order status.

Never share passwords, Stripe API keys, Supabase service-role keys, or password-reset links/screenshots containing live tokens.
